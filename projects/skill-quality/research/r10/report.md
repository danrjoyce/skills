# R10 bounded usefulness smoke assessment

## Decision

**No observed preference for v2. Stop this assessment without adding cases, tuning, or retesting to force a win.** All three policies produced correct first- and second-use artifacts in both supplied workflow families, and all six boundary cases refused unauthorized replacement while preserving state. No additional task facts were supplied and no corrective artifact repair was observed. The predeclared zero-intervention tie therefore provides no v2 advantage.

This is not an 18/18 end-to-end success result. Four consumers were interrupted during reporting. There were fourteen completed final notifications, seventeen report files, and only nine completed notifications observed within the three-minute cap. Artifact correctness, boundary behavior, reporting, timing and complete authorized-action history remain separate. V2's two draft consumers produced correct artifacts but did not complete final reporting before interruption.

The unchanged [protocol](protocol.md) fixed four authors and eighteen consumers before observations: twelve positive artifacts and six boundaries. All slots were admitted once, sequentially in fresh contexts. No replacement slot, resumed consumer, new case, corrective task feedback, package tuning, or paid API call was added. Experimental activity ended with the final consumer observed terminal at **22:50:28 UTC on 2026-10-02**, before the unchanged 23:28 experimental stop. The original overall budget began at 20:58 and still ends at 23:58. Publication remains a separately verified step.

## Measurement, custody and limitations

Before any consumer ran, coordinator inspection found that the original checker used read_text for exact Markdown comparison, potentially normalizing CRLF. The original source and freeze remain unchanged. [The separately retained v2 checker](check-artifacts-v2.py) changes only that read to read_bytes().decode('utf-8'); [the addendum](checker-addendum.json) records expected-output acceptance and CRLF rejection controls. Input and expected bytes did not change. All consumers were graded with v2.

Conservative intervals start at the allowance origin in the admission wrapper and end at observed terminal status, including admission/notification/supervisory overhead. They are not active-runtime or token measurements. Admission log writing sometimes occurred after the spawn response; records now include separate spawn-return observations and explanatory notes. The first five consumer terminal ledger entries initially used later reconciliation time; additive precision records and the final per-slot records identify the earlier observed terminal times. Exact cessation instants remain unknown. Interrupt request brackets span the deadline in some cases; this does not establish strict enforcement or a precise overrun. Original observations remain in the ledger.

All fifty prelaunch frozen files and all four selected package manifests were reverified unchanged after consumers. Exact local prompts remain in private local custody. Public prompt copies omit only the generic private coordinator/approval paragraph, with original and public hashes and the omission in [prompt curation](prompt-curation.json). Public copies are not the full original prompts; the freeze includes hashes for locally retained originals. Runtime prompt.txt files are excluded from consumer publication copies. This is partial public prompt custody, not byte-for-byte public reconstruction of every prompt. No private coordination handoff or denied R6 archive is part of the publication set.

The assessment is same-team, unblinded, single-host synthetic development evidence. Workers were instructed to read only assigned inputs/packages and their own prior use, but shared readable storage was not an isolation barrier. Directory/collision mechanisms were known from prior development. Fully specified contracts cannot establish v2's advantage at recovering ambiguous real-world requirements. R10 fixes the earlier directory-state ambiguity for every policy; cross-round improvement cannot be causally attributed to v2. One author per policy/family and one consumer per slot offer no useful population-level superiority estimate.

Full authorized-action history, hidden tool activity, authenticated serving model, token usage, backend cost and native skill discovery remain unknown. Final bytes establish preservation only at observed endpoints. No symlink/race security claim, native-loading result, safety rate, broad adoption recommendation or multi-model conclusion follows. The [independent final review](final-review.md) checks this evidence and recommendation boundary. Research stops with this deliverable; stronger validation is optional future work, not another active experiment.

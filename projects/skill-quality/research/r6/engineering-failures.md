# Retained R6 setup failures and limits

All entries below are engineering/setup evidence, not creator-performance failures.

1. The first shell copy used a relative `skills-r5` source while already inside that directory, so `cp` failed. The following R5 tests still ran and passed. The copy was repeated from the parent directory successfully; 45 starting project files then matched the remote tree by Git blob identity.
2. An orchestration expression used an invalid JavaScript regular-expression literal. The cell failed before any tool ran. A corrected literal/filter completed the source inventory.
3. Storing unchanged public baseline Markdown directly inside the project caused the frozen R4 checker to reject upstream em-dash prose. Upstream instructions were not edited to pass. Exact public UTF-8 bytes were stored in a JSON source archive and extracted into the experiment's separate baseline directory. The archive preserves every original blob and license; subsequent project checks pass. This format also prevents the project's local-link checker from treating upstream illustrative links as this project's links.
4. Redirecting a checker into a `.json` file inside the recursively checked tree created an empty file before the checker scanned it, causing JSON parsing to fail. The empty capture is retained as `evidence/r4-empty-capture.txt`. Re-running with capture outside the checked tree, then copying the valid output, passed. This was a capture-path error, not evidence of a malformed frozen R4 design.
5. A child-context `cloud_threads.list_environments` call returned `RuntimeError: The invoking thread is not attached to an Aeon`. It does not establish that every environment is unavailable. The parent reported no usable desktop or saved environment; existing dot-cloud shell operations were directly observed to work.
6. A routine `cat ... | head` inventory inspection emitted a broken-pipe notice after the requested prefix was printed. No artifact changed; the full inventory remained readable.

The native worker API has no exposed authoritative child action stream or serving-model/token/cost counters. A start/status/interrupt interface is not a proof of exact cancellation or per-boundary supervision. Self-reported call counts, mutable adapter logs and final file hashes have narrower evidential scope. The primary comparison is methodology-gated; the predeclared explicit-load diagnostic remains separate.

7. A checkpoint helper used a star import that shadowed the datetime module with its class, so supervision-sidecar creation failed before writing that sidecar. Qualified imports fixed the helper; no worker was relaunched and earlier journal entries remain.

8. An initial remote PR-info lookup used `repo_full_name` rather than the connector's `repository_full_name` argument and was rejected before action. The corrected read verified the unchanged remote head. The preceding context's publication cell had an uncertain tree-create outcome, but no commit-create or ref-update had been issued. The continuation verified the unchanged head and will build a new completed-evidence tree, not blindly retry the unfinished payload.
9. O0 reports one failed patch against a generated template before its first completed draft. No edit occurred from that patch; its initial package and all checks remain retained. This is an attributed authoring incident, not a discarded generated candidate.
10. A0 was interrupted at its declared 18:56:55 UTC wall deadline after producing a complete initial package and receiving one sequential development observation. It did not finish its creator report. The initial package is selected under the unchanged R4 last-completed-draft rule; the incomplete reporting and unknown final call count remain explicit. No extra authoring turn or replacement report was granted after the deadline.
11. Large evidence JSON uses a lossless gzip/base64 envelope for bounded publication calls. `archive-io.py` checks both compressed and exact uncompressed hashes and recovers JSON bytes only. This is storage representation, not a source or score change; original archive bytes and file metadata remain recoverable. No archived script or symlink is implicitly executed or followed.

12. The first final R6 consistency check treated a later attributed cost-clarification event as a state snapshot and raised `KeyError: state`. Filtering only actual state records fixed the checker. No runtime worker or oracle result changed or was repeated.

13. Publication of the compressed public-source archive was denied as an opaque-data disclosure risk. One identical retry with exact user transcript evidence and a decoded field/blob audit was denied again. That upload stopped. No alternative route sent the denied bytes. All three compressed source/runtime archives are retained locally and excluded from publication; a hash-only retention manifest, pinned public URLs and curated synthetic case/semantic artifacts disclose the reduced evidence delivery.
